# Project Management Showcase – Trello

## Overview
This repository demonstrates my hands-on experience using Trello
for managing a software project using a Kanban workflow.

## What I Did Using Trello
- Created a Kanban board with Backlog, Requirements, Design,
  Development, Testing, and Done stages
- Defined MVP scope, functional and non-functional requirements
- Used labels for task type, priority, and module classification
- Added checklists, due dates, and custom fields
- Tracked progress using In Progress and Testing workflows

## Tools & Concepts
- Trello
- Kanban
- Agile task management
- Requirement analysis
- Task prioritization
